MARS Link – Hospital & Blood Bank Resource Portal

Part of the MARS Ecosystem (Mobile Automated Repository for Saving Lives)

MARS Link is the dedicated web portal for hospitals and blood banks in the MARS ecosystem. It enables real-time blood inventory management, request handling, donor coordination, and communication with state authorities. The portal integrates seamlessly with MARS Prime (governance) and MARS Pulse (donor mobile app) to build a unified national blood supply chain.

🌐 Purpose

MARS Link empowers healthcare facilities to:

Update and track blood inventory

Raise, validate, and fulfill blood requests

Coordinate with nearby hospitals and authorities

Mobilize donors efficiently through AI-driven matching

Ensure compliance and transparent operations

🚀 Key Features
1. Real-Time Inventory Management

Add, edit, or update stock levels

Auto-sync with MARS Prime dashboards

Low-network support using SMS stock updates

2. Geo-Prioritized Request System (GPRS)

Intelligent routing of blood requests based on urgency using three tiers:

Tier 1: 0–15 km (local district supply & donors)

Tier 2: 15–37 km (neighboring districts)

Tier 3: 120 km+ (statewide emergency routing)

3. Request Lifecycle Management

Raise blood requests instantly

Approve/decline inter-hospital transfers

Track request status end-to-end

View matched donor details in real-time

4. Governance Tools

Donor deferral management

Compliance tracking

Automated audit logs

Authority notifications

5. Offline Mode (SMS Based)

Update stock → via formatted SMS

Receive donor confirmations

Full functionality for rural/low-network regions

6. Integrated Alerts & Notifications

Shortage alerts

Donor availability updates

Authority messages

Disaster Mode activation (GDRA)

🛠 Tech Stack

Frontend: React / Next.js

Backend: Node.js / Python APIs

Database: PostgreSQL / MongoDB

Cloud: AWS / Azure / GCP

Security: AES-256, JWT, RBAC

Offline Layer: SMS/IVR Gateways

Geo Services: Google Maps / OpenStreetMap
